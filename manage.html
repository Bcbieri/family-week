Making a save key

  1. On github.com, open Settings → Developer settings → Personal access tokens → Fine-grained tokens, then Generate new token.
  2. Name it Family Week. Set expiration to No expiration, or a year.
  3. Repository access: Only select repositories, choose family-week.
  4. Permissions: Contents → Read and write.
  5. Generate, copy the key, and paste it above. Use the same key on Eden's phone.
